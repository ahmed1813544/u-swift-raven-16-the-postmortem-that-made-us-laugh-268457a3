Entry for the make.fun bounty [The Postmortem That Made Us Laugh](https://make.fun/bounty/u-swift-raven-16-the-postmortem-that-made-us-laugh-268457a3): a one-sentence account of an AI coding agent misunderstanding a rename request and wrecking a billing email.

## How it works

`main.py` (Python 3, stdlib only) writes the story deterministically to `/output/entry.txt` (or the path in `OUTPUT_PATH` / `MAKEFUN_OUTPUT_PATH` / `ENTRY_OUTPUT`).

```sh
python3 main.py
```
